# Вспомнить решение

## Шаги

1. Найди по теме файлы в `decisions/`, `specs/` и `calls/`.
2. Прочитай найденное.
3. Ответь коротко: что решили, когда, на основании чего.
4. К каждому утверждению дай ссылку `[[имя-файла]]`.
5. Нашёл два документа, которые спорят между собой, — покажи оба и скажи, какой новее. Не выбирай за человека.
6. Ничего не нашёл — так и скажи. Не собирай ответ из догадок.

## Правила

- Ничего не записывай. Этот скилл только читает.
- Ответ без ссылок не выдавай.
