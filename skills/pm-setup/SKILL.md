# Настройка базы

## Шаги

1. Спроси, в какой папке создать базу. Предложи текущую.
2. Создай папки `raw/`, `calls/`, `decisions/`, `specs/`.
3. Скопируй `AGENTS.md` из этого скилла в корень базы.
4. Спроси, какими агентами пользуется человек. Для каждого создай ссылку на `AGENTS.md`:
   - Claude Code — `CLAUDE.md`
   - Cursor — `.cursor/rules/pm-second-brain.mdc`
   - Gemini CLI — `GEMINI.md`
   - Codex — `AGENTS.md` уже подходит
5. Предложи выполнить `git init` и первый коммит.
6. Покажи, что получилось, и назови следующий шаг: положить транскрипт в `raw/` и запустить `/pm-call`.

## Если папка занята

Ничего не перезаписывай. Скажи, какие файлы уже есть, и спроси, что делать.
